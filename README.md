# Revenue Assurance & Marketing Forecast — portfolio demo

A single-file, self-contained dashboard that reviews a **fictional** group's ("NexaGroup")
marketing-driven revenue position across 16 business units and projects where each unit
lands by year-end if the current quarter's trend holds.

> **Demo data only.** Every company, business-unit name, code and figure is synthetic.
> Numbers are deterministic, seeded/invented values that mimic the shape of a real
> revenue-assurance extract so the charts and KPIs render — no real company, ledger or
> transaction appears. See [`PROFILE.md`](PROFILE.md) for the full project write-up.

## Tabs

Overview · Forecast · Efficiency · Actions · Early Warnings · SBU Detail · Assumptions & Method.

## Run / deploy

Static single file — no build, no backend:

```bash
open index.html          # double-click works too
```

Vercel: import the repo, framework preset **Other**, root `.`, no build command.
